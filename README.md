# CineWave

یک رابط آماده و سبک برای برنامه تماشای فیلم و سریال، مناسب GitHub Pages.

## اجرا
فقط `index.html` را باز کنید. برای انتشار، کل پوشه را داخل یک Repository قرار دهید و GitHub Pages را روی branch اصلی و پوشه root فعال کنید.

## امکانات
- صفحه اصلی و Hero
- جست‌وجوی فارسی
- فیلتر ژانر
- فیلم و سریال
- جزئیات محتوا
- فصل/قسمت نمونه
- Video Player با HTML5
- لیست من با localStorage
- طراحی Responsive برای موبایل و دسکتاپ
- بدون کتابخانه خارجی و بدون build step

## افزودن ویدئوی مجاز
در `app.js` مقدار `video` برای فیلم یا مقدار سوم هر episode را با URL مستقیم فایل ویدئویی که اجازه پخش آن را دارید پر کنید.
